# A La Carte Miami — Design System

> UI/UX Pro Max · Restaurant / Premium Wellness Cafe  
> Style: **Hero-Centric + Minimalism / Editorial** (classic, on-brand)

## Colors (locked)
- Navy `#171842` — header, CTA, text on cream
- Cream `#FFF3D2` — page background
- Cream text `#FFF3D2` on navy

## Typography
- Display: **Cormorant Garamond** — elegant, classic
- Body: **Source Sans 3** — clean, readable

## Pattern
1. Hero — H1/H2 + location + CTA bottom; `<picture>` desktop 21:9 / mobile 9:16
2. About (trust copy + Kosher)
3. Community (split image + app CTA — coming soon)
4. Food (featured + mosaic grid)
5. Interior — horizontal scroll + nav arrows + thin scrollbar
6. Locations + map
7. Contact

## Hero copy (SEO)
- Location (small caps): Hallandale Beach, Florida → `#locations`
- **H1:** Á La Carte Miami
- **H2:** Thoughtfully prepared food you can feel good about
- CTA: Start Your Order (fixed bottom)

## Mobile UX notes
- Hamburger right; menu panel slides from right
- Hero text: top-aligned; CTA stays bottom
- Community buttons: centered in `section--alt`

## Effects
- Transitions 200–250ms ease
- Subtle hover on buttons/links
- No glassmorphism, neon, brutalism, AI gradients
